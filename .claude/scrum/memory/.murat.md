### Coverage Gaps (Critical)
- Epic 6 (Integration & Quality) is NOT STARTED - this is the testing epic
- No systematic test coverage metrics
- No CI test gates visible
- Shell-based E2E tests exist but unclear if automated
- Need to assess actual test coverage vs. target (80%+)

### Test Strategy Priorities
1. **Assess current coverage** - Run existing tests, measure coverage
2. **Backend unit tests** - LLM client, MCP client, state manager, routes
3. **MCP tool tests** - Each of the 14+ tools needs test coverage
4. **Integration tests** - Backend <-> MCP, Backend <-> Redis
5. **E2E tests** - Full message flow: Telegram -> Backend -> LLM -> Response
6. **Error scenario tests** - Graceful degradation for all external services
7. **Performance tests** - First token latency, tool call completion, concurrent users

### Test Commands
- `make test`

- `docker compose exec mcp-server python -m pytest tests/`

### Quality Concerns
- Production system running without comprehensive test coverage
- Large files (media_sender 38KB, backend_client 22KB) likely have complex logic untested
- Multiple LLM providers each need fallback testing
- Memory circuit breaker logic needs edge case testing
