### Provider mock patterns (Story 23.1 — useful for any future provider work)
- Build a `_FakeTrace` / `_FakeGeneration` pair that captures `init_kwargs` and `end_kwargs` on `generation()` / `end()` calls. Patch `api.providers.<name>.get_current_trace` to return the fake.
- Gemini stream chunks: build `_Chunk(candidates=[_Candidate(text=..., finish_value=1, finish_name="STOP")], usage_metadata=_UsageMetadata(prompt_token_count=N, candidates_token_count=M))`. Final chunk carries `usage_metadata`; intermediate chunks just carry text.
- Use `MagicMock(side_effect=AssertionError("must not be called"))` to assert a method is NEVER invoked — fires on regression.
- ChatGPT streams: capture the request payload via a closure `_CapturedRequest()` so you can assert `stream_options.include_usage=True` on the wire. SSE lines: `f"data: {json.dumps(payload)}"` + `"data: [DONE]"`.
- Mid-stream 429 simulation: yield N chunks with usage_metadata then `raise Exception("ResourceExhausted: 429 ...")` from `__next__`. Provider wraps as `RateLimitError`. Test `_trace_error_generation` recorded the captured `last_usage` faithfully.
