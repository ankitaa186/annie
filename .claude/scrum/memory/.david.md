## Development Patterns
- Provider pattern for LLMs (base class + implementations)
- Registry pattern for MCP tools
- Redis for all caching/state (profiles, sessions, rate limits, memory queues)
- Structured logging with JSON format
- API key masking in logs
- Docker Compose with health checks
- Feature branches: `story/{N}.{M}-{description}`

## Build/Test
- `make start` / `make rebuild` / `make test`
- pytest for testing (backend/tests/ has unit, integration, e2e, proactive dirs)
- Tests exist but coverage is incomplete

## Standing Directives
- **Source of Truth**: The codebase and git log are the ONLY source of truth. The BMAD planning docs in `docs/` (PRDs, architecture plans, epic files, sprint plans) may be outdated and MUST NOT be treated as authoritative. When implementing stories, read the actual code and `git log` / `git diff` to understand current state, not the planning documents.
- **Single-branch dev**: Ankit's preference is to work directly on `develop`. Don't create `story/*` feature branches.
- **Tests run inside containers**: `docker compose exec -T backend python -m pytest tests/` (and similar for `mcp-server`). The backend mount is `./backend:/app`.

## Story 23.1 Implementation Notes (2026-04-25)
- Provider streaming paths in `backend/api/providers/{gemini,chatgpt}_provider.py` now read tokens from the SDK's final-chunk `usage_metadata` (Gemini) / `usage` block (ChatGPT, with `stream_options.include_usage=True`). When SDK doesn't deliver usage, `generation.end()` is called with the `usage` kwarg **omitted entirely** (Langfuse v2 coerces explicit Nones to 0 → false-zero rows pollute reconciliation).
- `count_tokens()` deleted from streaming code — was a billable round-trip + had a silent `except: pass` that produced the Apr-04 placeholder traces.
- Error-path tracing: `_trace_error_generation` helpers in both providers, called from each except block. `try/finally` around `generation.end()` at every call site (4 sites). Per Parminder: don't extract a context manager — keep diff bounded.
- Hoisted `trace = get_current_trace()` and `final_usage = {}` out of the `with self.client.stream(...)` block in chatgpt_provider so outer except handlers can reach them.
- New `scripts/cost_reconciliation.py` — Langfuse REST → per-day markdown table for operator reconciliation against Google Cloud Console billing detail. `--dry-run` for smoke testing.
- Mounted `./scripts:/app/scripts:ro` in `docker-compose.yml` (backend + proactive-worker) so the script + smoke test are reachable inside the test container. Requires `docker compose up -d --force-recreate <service>` once.
