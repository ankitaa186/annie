# David's Project Understanding (Developer)
Last Updated: 2026-04-16 10:00

## Project Overview
Annie - microservices AI companion. Python 3.12+ backend (FastAPI), MCP server, Telegram bot, React web UI. Docker Compose orchestration.

## Codebase Familiarity

### Backend (`backend/api/`)
- `main.py` - FastAPI app entry point
- `llm_client.py` - Unified LLM client with provider management
- `mcp_client.py` - MCP server communication (JSON-RPC 2.0)
- `memory.py` / `memory_client.py` - Memory storage/retrieval via agentic-memories
- `profile.py` - User profile with Redis caching
- `prompts.py` - System prompt construction
- `state.py` - Redis-based conversation state
- `status.py` / `status_summarizers.py` - Status endpoint logic
- `config.py` - Environment configuration
- `providers/` - grok_provider, chatgpt_provider, gemini_provider, base provider
- `routes/` - chat.py, stream.py, conversations.py, session.py
- `proactive/` - Full proactive AI module (agent, evaluators, gate, triggers, worker)
- `middleware/` - cloudflare_auth, rate_limiter
- `observability/` - langfuse_client, tracing, cost tracking
- `models/` - conversation, file_attachment

### MCP Server (`mcp_server/`)
- `server.py` - MCP server with JSON-RPC 2.0
- `tools/` - 14+ tool modules: web_search, web_crawl, reddit_search, home_assistant, portfolio, memory, profile, stock_analysis, sec_edgar, terminal, triggers, browser, registry

### Telegram Bot (`telegram_bot/`)
- `bot.py` - Main bot implementation
- `backend_client.py` - HTTP client to backend API
- `file_handler.py` - File detection, download, validation, base64 encoding
- `media_sender.py` - Media sending logic
- `handlers/` - Message routing

### Web (`web/`)
- React + Vite + Tailwind
- Scaffolded but incomplete

### Browser (`browser/`)
- Patchright-based browser automation with VNC sidecar

## Development Patterns
- Provider pattern for LLMs (base class + implementations)
- Registry pattern for MCP tools
- Redis for all caching/state (profiles, sessions, rate limits, memory queues)
- Structured logging with JSON format
- API key masking in logs
- Docker Compose with health checks
- Feature branches: `story/{N}.{M}-{description}`

## Build/Test
- `make start` / `make rebuild` / `make test`
- pytest for testing (backend/tests/ has unit, integration, e2e, proactive dirs)
- Tests exist but coverage is incomplete
