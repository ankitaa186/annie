## Lessons Learned
- When dropping an enum to free-form, keep a strict-but-explicit validator (don't silently normalize) — the LLM learns from validation errors within the same turn. Use `re.fullmatch`, not `re.match` (`\n` snuck through `match`).
- Keep back-compat aliases (e.g., `MAX_SLOT_CHARS = MAX_VALUE_CHARS`) when renaming public constants — callers outside the module may still import the old name; the cost is one line.
